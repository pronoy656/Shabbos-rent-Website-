

আমি তোমাকে এটাকে UI architecture + frontend business-flow architecture হিসেবে বুঝাচ্ছি।

প্রথমে Core Concept বুঝি

এই system-এ মূল entity হবে:

Ambassador
    ↓
Referral / Attribution
    ↓
Apartment Listing
    ↓
Model A / Model B
    ↓
Rental Events
    ↓
Commission Ledger
    ↓
Payout

এখন গুরুত্বপূর্ণ বিষয় হলো:

Ambassador নিজে কোনো apartment-এর মালিক না-ও হতে পারে

একজন Ambassador:

Ambassador A
   │
   ├── Apartment 1 → Owner X → Model A
   ├── Apartment 2 → Owner Y → Model B
   └── Apartment 3 → Owner Z → Model A

তাই frontend-এ Ambassador-কে শুধু একটা user হিসেবে দেখালে হবে না।

তাকে system-এর মধ্যে referral owner / commission beneficiary হিসেবে ধরতে হবে।

পুরো System-এর ৪টি আলাদা User Context

আমি frontend-কে ৪টি context-এ ভাগ করতাম:

1. Public / Owner Listing Flow
2. Ambassador Portal
3. Admin Ambassador Management
4. Existing Owner Dashboard Integration

এই চারটা আলাদা হলেও একে অপরের সাথে connected থাকবে।
