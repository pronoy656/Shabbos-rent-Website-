হ্যাঁ, এখন তোমার requirement একদম clear। তুমি এখন backend বানাতে চাচ্ছো না—তুমি আগে frontend-এ পুরো Ambassador Program-এর complete business flow-টা hardcoded/mock data দিয়ে simulate করতে চাচ্ছো, যাতে:

পুরো business logic visualise করতে পারো
Ambassador কীভাবে কাজ করে সেটা বুঝতে পারো
Admin → Ambassador → Owner → Listing → Rental → Commission → Payout flow দেখতে পারো
সব possible states test করতে পারো
Backend তৈরি হলে শুধু mock data/API logic replace করতে পারো

এটা আসলে খুব ভালো approach।

তোমার Frontend-এর জন্য সঠিক Approach

তুমি frontend-এ একটি Business Logic Simulator বানাবে।

Mock Data
    ↓
Frontend Business Logic
    ↓
UI State
    ↓
User Action
    ↓
State Update
    ↓
UI Update

Backend আসার পর:

API Response
    ↓
Same UI
    ↓
Same Business Flow

অর্থাৎ UI নতুন করে বানাতে হবে না।
